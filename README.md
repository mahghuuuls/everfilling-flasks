# Everfilling Flasks

A Minecraft 1.12.2 Forge mod. Adds a rechargeable healing Flask that lives in its own equipment
slot and is drunk by holding a key, in the spirit of souls-like games. Other mods can add their own
Flasks, modifiers, and HUD through a public API.

Requires Inventory Button Bar on client and server.

Repository documentation is written at release. This file is a placeholder for the initialized
project baseline.
